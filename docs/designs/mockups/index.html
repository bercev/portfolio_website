PORTFOLIO REDESIGN — 4 DIRECTIONS

Design Mockups

Four self-contained HTML mockups for the portfolio redesign. Each uses the real site content (Berat Ercevik — Software Engineer) and is fully interactive in the browser. The current production design is untouched.

01

Editorial Brutalist

Ink-on-paper. Massive black display type, hard 2px rules, numbered sections, hover-invert rows, one orange accent. Zero radius, zero shadows.

 02

Liquid Glass Spatial

Deep space-blue gradient with drifting color orbs, frosted-glass cards, floating pill nav, gradient-clipped hero name. Calm and premium.

 03

Immersive 3D Journey

Near-black depth. Hero name tilts with the pointer, sections are stations along a glowing cyan→emerald path, cards tilt in 3D on hover.

 04

Horizontal Cinema

The site as a film: sideways scenes with letterbox bars, film grain, timecode, scene slates, and an amber accent. Arrow keys move scenes.
Mockups only — not linked from the site. Open any file directly, or serve: npx serve docs/designs/mockups
