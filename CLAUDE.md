## Conventions

- **Next.js 16 differs from older docs** — consult `node_modules/next/dist/docs/` (start at `01-app/`) before writing Next.js code (enforced by AGENTS.md).
- **Global type helpers** — `LayoutProps<"/route">`, `PageProps<"/route">` need no imports.
- **Tailwind v4** — `@import "tailwindcss"` in `globals.css`; `@theme inline` maps `--background`/`--foreground` → `bg-background`/`text-foreground`.
- **Dark mode** — `@media (prefers-color-scheme: dark)` in `globals.css` (no class toggle); components use `dark:` variants.
- **Fonts** — Geist Sans/Mono via `next/font/google` in `app/layout.tsx` → `font-sans`/`font-mono`.
- **Alias** — `@/*` → repo root.
- **AGENTS.md auto-regenerated by `next dev`** — keep the `BEGIN:nextjs-agent-rules` block.
- **Use the 21st MCP when downloading components** — search `mcp__21st__search` / `mcp__21st__search_picker`, fetch code with `mcp__21st__get_component`, themes with `mcp__21st__get_theme`, or generate new UI with `mcp__21st__generate` instead of hand-writing from scratch.
- **Use the `frontend-design` skill when building or styling UI** — invoke it before writing component/JSX or CSS so designs follow its system (typography, color, spacing, layout) instead of ad-hoc choices.
- **Next.js MCP (`next-devtools-mcp`)** — configured in `.mcp.json`; connects to the dev server's built-in `/_next/mcp` endpoint, so `npm run dev` must be running. Tools: `get_routes`, `get_errors`, `get_logs`, `get_page_metadata`, `get_project_metadata`, `get_server_action_by_id` (plus Turbopack-only `get_compilation_issues`, `compile_route`). See `node_modules/next/dist/docs/01-app/02-guides/mcp.md`.
